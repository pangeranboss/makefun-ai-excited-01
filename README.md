"The Leap" — a giant goldfish bursts out of a tiny teacup and leaps for a huge full moon, shouting WHOA! A single deterministic Node program (standard library only) draws the whole image procedurally at runtime — deep midnight blue, saturated orange-gold, a frozen splash crown, motion dashes and droplets — and writes it as a 1024×1024 PNG with a from-scratch PNG encoder (zlib deflate + CRC32).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
